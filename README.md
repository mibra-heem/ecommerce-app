## About Mohart

A modern, full-featured e-commerce application built using **Flutter (frontend)** and **Laravel (backend)**. This app offers a smooth online shopping experience with real-world functionality including payments, product listings, and user-friendly interactions.

---

## ✨ Features

- 🧾 Product listing vertical & horizontal.
- Detailed product info screen
- 🛒 Add to cart, wishlist, and remove functionality
- 📦 Full checkout process with:
  - Address form
  - Payment method selection (Stripe / Cash on Delivery)
  - Order confirmation
- 💳 Stripe Payment Integration (with client secret flow)
- 📡 Laravel REST API integration
- 🎯 Bloc/Provider state management
- 📱 Mobile-friendly and responsive design
